# eCONTACT — Приложение для управления контактами

Простое настольное приложение на C# (Windows Forms) для сохранения и управления контактными данными членов семьи и друзей. Разработано в соответствии с учебным заданием.

---

## Описание

Приложение **eCONTACT** представляет собой программу для ведения базы контактов. Позволяет добавлять, обновлять, удалять, искать и сортировать контакты. Данные хранятся в локальной базе данных **MS SQL Server**.

---

---

## Возможности

- ✅ **Добавить новый контакт** — создание записи в базе данных
- ✅ **Обновить существующий контакт** — изменение данных выбранной записи
- ✅ **Удалить существующий контакт** — удаление записи с подтверждением
- ✅ **Фильтровать контакты** — живой поиск по всем полям (имя, фамилия, телефон, адрес)
- ✅ **Сортировать контакты** — сортировка по любому столбцу в таблице

## Установка и запуск

### Предварительные требования

1. **Visual Studio** 2020 или новее (с компонентом `.NET desktop development`)
2. **SQL Server** 2020 или новее (Express/Developer/Standard)
3. **SQL Server Management Studio (SSMS)** для выполнения скрипта БД

### Подготовка

Клонирование репозитория: 
```bash
git clone https://github.com/Kiwinze/econtact.git
cd econtact
```

### Настройка строки подключения:

В файле Form1.cs, найдите сверху строку:
```csharp
string connectionString = @"Data Source=localhost;Initial Catalog=ContactDB;Integrated Security=True;";
```
Измените параметр Data Source в соответствии с вашей базой данных, а также и иные параметры в соответствии с вашим SQL Server

---

### Создание базы данных

Выполните скрипт `Database/CreateDatabase.sql` в **SQL Server Management Studio**:

```sql
-- Создание базы данных
CREATE DATABASE ContactDB;
GO

USE ContactDB;
GO

-- Создание таблицы контактов
CREATE TABLE Contacts (
    ContactID INT PRIMARY KEY IDENTITY(1,1),
    FirstName NVARCHAR(50) NOT NULL,
    LastName NVARCHAR(50) NOT NULL,
    ContactNo NVARCHAR(20) NOT NULL,
    Address NVARCHAR(200) NULL,
    Gender NVARCHAR(10) NULL
);
GO
```
